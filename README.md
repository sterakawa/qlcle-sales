# qlcle-sales

QLCLE社内用の販売管理システムです。

最初の機能は請求書作成です。  
FileMakerのように「1伝票ずつ見る」感覚を残しつつ、右側のバインダーから過去の請求書をめくれるUIを目指します。

## 最初のゴール

- 新規ボタンで白紙の請求書を作成
- 取引先を選択
- 明細項目を選択または直接入力
- 数量 × 単価を自動計算
- 小計・消費税・合計を自動計算
- 過去の請求書を参照
- 複製
- PDF / 印刷
- 将来的にSupabaseへ保存

## 設計思想

利用者は「売上管理のための入力」をしません。  
請求書・見積書を作成する日常業務の中で、明細データが自然に構造化され、将来の売上分析に使える状態を作ります。

### 売上分類（予定）

- サービス基本料金
- カスタマイズ費
- 人件費
- 交通費
- 搬入・テスト稼働などの追加費用
- 機材費
